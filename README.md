# 🎓 Course Management System

A full-stack Course Management System built using Flask, MySQL, and Bootstrap 5.

This web application allows users to register, login securely, create courses, enroll students, and manage courses through a clean admin dashboard interface.

---

## 🚀 Features

### 🔐 Authentication System
- User Registration (with password hashing)
- Secure Login
- Session-based authentication
- Logout functionality

### 📚 Course Management
- Add new courses
- View all created courses
- Delete courses
- Enroll students into courses
- Automatic cascade delete of enrollments

### 🎨 Modern UI
- Bootstrap 5 Professional Layout
- Admin Dashboard with Sidebar
- Responsive Design
- Dark / Light Mode Toggle
- Clean University Portal Design

---

## 🛠 Tech Stack

- **Backend:** Flask (Python)
- **Database:** MySQL
- **Frontend:** HTML, CSS, Bootstrap 5
- **Authentication:** Werkzeug Password Hashing
- **Session Management:** Flask Sessions
